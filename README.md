### Design system
One language everywhere: indigo→blue→teal brand gradients, emerald accents, 20–24px radii, soft layered shadows, glassmorphism, Sora/Inter typography, consistent spacing, spring easing (`cubic-bezier(0.16,1,0.3,1)`), card-lift hovers, scroll reveals, and full **dark mode** (class-based, persisted, respects system preference).

### Performance
React.lazy code-splitting per page · manual vendor chunks (react, motion, charts, query) · memoised chat messages · IntersectionObserver reveals · skeleton loaders · no layout thrash.
